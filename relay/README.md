# basehub-relay — ретранслятор Basehub Remote

Соединяет приложение Basehub на телефоне с Basehub на компьютере, когда они в разных сетях.
Компьютер сам держит исходящее соединение, поэтому открывать порты у клиента не нужно.

**Ретранслятор не видит содержимое.** Телефон и компьютер шифруют всё между собой (Noise:
сопряжение `XXpsk3` по коду с экрана компьютера, дальше `KK` по сохранённым ключам). Ретранслятор
пересылает конверты «от кого — кому — шифротекст», держит в памяти список устройств в сети и ничего
не пишет на диск. Вход на ретранслятор — подпись ed25519: занять чужой id нельзя.

По умолчанию Basehub работает через `wss://api.basehub-tools.ru/v1/ws`. Свой ретранслятор нужен,
если данные не должны проходить через чужой сервер: укажите его адрес в Basehub
(«Настройки → Удалённый доступ → Адрес ретранслятора»), он попадёт в QR-код, и телефон подключится к нему сам.

## Запуск

Docker:

```sh
docker run -d --name basehub-relay --restart unless-stopped -p 127.0.0.1:8790:8790 \
  -e RELAY_TRUST_PROXY=1 ghcr.io/rus1am89/basehub-relay:latest
```

Или бинарник под systemd: `basehub-relay` в `/usr/local/bin`, юнит — `basehub-relay.service`.

Перед ретранслятором нужен HTTPS с поддержкой WebSocket (Caddy, nginx, прокси Synology DSM —
с заголовками `Upgrade`/`Connection`). Пример для Caddy:

```
relay.example.ru {
    reverse_proxy 127.0.0.1:8790
}
```

Адрес для Basehub: `wss://relay.example.ru/v1/ws`. Проверка: `https://relay.example.ru/health` → `ok`.

## Настройки (переменные окружения)

| Переменная | По умолчанию | |
|---|---|---|
| `RELAY_LISTEN` | `0.0.0.0:8790` | адрес и порт |
| `RELAY_TRUST_PROXY` | `0` | `1` — брать IP клиента из `X-Forwarded-For` (только за своим прокси) |
| `RELAY_MAX_CONN_PER_IP` | `20` | соединений с одного IP |

Ограничения: кадр до 128 КБ, до 200 сообщений в секунду на соединение, тишина дольше 90 с —
отключение, приглашение для ввода кода живёт 5 минут и выдаётся один раз.

## Сборка

```sh
cargo test                     # в relay/: сквозной тест через живой ретранслятор
cargo build --release
docker build -f relay/Dockerfile -t basehub-relay .   # из корня репозитория
```
